# Sport in den 1920er Jahren

Dies ist ein bearbeitbares Starter-Projekt für ein Schul-Website-Projekt.

## Dateien
- `index.html` – Hauptseite
- `style.css` – Layout, Farben, Typografie
- `animations.css` – Hover- und Reveal-Effekte
- `script.js` – Menü und Scroll-Animationen
- `quiz.js` – Quiz-Auswertung

## Was du später ändern kannst
- Texte
- Bilder
- Quellen
- Quizfragen
- Video-Embed

## Design
- Heller Hintergrund
- Dunkelblau als Akzentfarbe
- Seriös, ruhig, historisch angelehnt
